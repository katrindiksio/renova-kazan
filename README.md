# Ремонт Казань — лендинг

Лендинг компании по ремонту квартир в Казани (средний сегмент): Hero, «1 подрядчик вместо 10 специалистов», цены, калькулятор, что входит в стоимость, 4 платежа, гарантия, фотоотчёт, объекты с «до/после», ситуации, FAQ и форма заявки.
Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, shadcn/ui, шрифты Urbanist и Manrope.

## Запуск на своём компьютере

1. Установите [Node.js](https://nodejs.org) версии 20.9 или новее (LTS) и Git.
2. Скачайте проект: `git clone <адрес репозитория>` (или скачайте архив из репозитория и распакуйте).
3. На Windows проще всего дважды щёлкнуть по файлу `start-windows.bat`: он сам установит зависимости (при первом запуске), запустит сайт и откроет браузер. Или вручную: в папке проекта выполните:

```bash
npm install
npm run dev -- -p 47213   # режим разработки: http://localhost:47213
```

Готовая сборка (быстрее и ближе к тому, что увидят посетители):

```bash
npm run build
npm start -- -p 47213
```

Для публикации в интернете подойдёт любой хостинг с Node.js, например Vercel: подключите репозиторий, остальное он настроит сам.

## Где что менять

- `lib/site.ts` — весь контент: название бренда, меню, тексты hero, CTA-ссылки (`#calculator`, `#projects`), преимущества, путь к фото и `objectPosition`.
- `public/hero-apartment.jpg` — временное фото (Pexels, свободная лицензия). Замените файл или поменяйте путь в `lib/site.ts` (при замене файла под тем же именем перезапустите `next dev`, иначе кэш оптимизатора отдаст старую картинку).
- `app/globals.css` — токены: палитра, `--container-site`, `--inset` (поля вокруг hero), `--hero-radius`, `--hero-pad` (внутренний отступ контента), `--nav-h`, `--hero-min-h`.
- `components/site/` — `navbar`, `brand`, `mobile-menu`, `hero` (фото на всю площадь hero, текст, две отдельные кнопки), `advantages` (один составной блок-«выемка» в правом нижнем углу).

## Композиция

Повторяет Hero Xurya: чистый navbar над крупным скруглённым блоком, фото занимает 100% блока, заголовок и описание слева, под ними две самостоятельные кнопки, преимущества — одна составная панель цвета страницы в правом нижнем углу с вогнутыми скруглениями, как в референсе. Поверх светлого фото лежит умеренное равномерное затемнение (`bg-[rgb(12_16_22/0.36)]` в `hero.tsx`), текст белый.

## Фото

Фото (Hero, карточки цен в `public/pricing/`, пары «до/после» в `public/projects/` по схеме `N-before.jpg` / `N-after.jpg`, где N — номер объекта из `lib/site.ts`) с Pexels (бесплатное использование без атрибуции) — замените на реальные объекты компании перед запуском. Фото «до» в `public/projects/` сгенерированы по фото «после» (та же планировка и ракурс) и служат заглушками: подмените пары своими снимками тех же объектов.

Дизайн-система проекта (токены, компоненты, правила для новых секций): [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md).

## Шрифт

Urbanist подключён через `next/font/google` (`app/layout.tsx`, токен `--font-sans`). В Urbanist нет кириллицы, поэтому русские буквы отображаются запасным геометрическим шрифтом Manrope (те же начертания 400 / 500 / 700); латиница и цифры — Urbanist.

## Заявки

Форма «Смета за 24 часа» отправляет данные на `POST /api/lead` (`app/api/lead/route.ts`). Сейчас обработчик только проверяет заявку и пишет её в лог сервера. Чтобы заявки доходили до менеджеров, подключите в блоке «доставка» CRM, Telegram или почту.
